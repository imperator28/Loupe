            Open it before your CAD finishes loading.

            Loupe does one job: open a STEP file and let you look. Parts appear as they load, and you can orbit while the rest fills in. Every open is timed, so you can check it against your own CAD.

            Make it look the way you'll present it.

            Auto colour palettes, materials, see-through housings and pinned dimensions. Then capture at 2×, 3×, 5× or any scale on a transparent background, ready to drop into a review deck.

            See how it goes together.

            One Spread slider pulls the assembly apart. Drag any part along X, Y or Z with snapping, or move it by an exact distance. Save the layout and come back to it in one click.

            Cut it open. Lay it flat.

            Slide a section through any axis or face, with capped cuts. Then turn the cut into a filled 2D slice: the clearest way to show how parts mate.

            Measure like you would in CAD.

            Distance, edge length, gap between faces, radius, angle, area, volume and bounds. Loupe lights up what you're about to pick and snaps to circle centres, so the number is the one you meant. Pin results to keep them in view.

            Mass, before anyone asks.

            Assign materials from a library built around real products: aluminium, zinc alloy, PC, PA, FR4, silicone and more. Read the mass of a part, a subassembly or any selection.

            Every part, its own STEP. In one go.

            Tick the parts a vendor needs and Loupe writes each as a separate STEP or STL, named your way, every file checked as it's written. In a full CAD program that's a save-as per part.

            Trim it down. Send the rest.

            Hide what shouldn't leave the building and save the rest as one STEP, with the tree, names, colours and units intact. No deleting bodies, no suppressing components, no broken references.

            Outlines for the laser and the die cutter.

            Project a part flat at true 1:1 and save DXF, SVG or PDF with real arcs and circles. No drawing file, no title block, just the path.

            The Drawing workspace is new. Check each drawing before you cut.

            First open on macOS

            Loupe isn't code-signed yet. If macOS says it “is damaged”, open System Settings → Privacy & Security and click Open Anyway, or run the Open Loupe (first run) helper in the zip. From Terminal: xattr -dr com.apple.quarantine Loupe.app

            First open on Windows 11

            Run Loupe.exe. If SmartScreen warns about an unrecognized publisher, choose More info → Run anyway. Keep the unzipped folder together; Loupe loads its runtime from it.
