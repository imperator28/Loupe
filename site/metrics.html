Open

The program is closed and Windows' file cache is cleared, so nothing is read from memory. The clock starts at the double-click on the file and stops on the first video frame where the whole model is on screen. Creo has no way to open a file from the command line, so it replays a recorded File > Open; its file dialog and import prompt are inside the time.

Export

The linear stage is already open. The program is restarted before every run, so no export settings carry over. The clock starts when the tester presses a key before the first click and stops when the last STEP file lands in the folder; menus, file-type lists and export options all count. Every file written was checked to be a valid STEP file.

Setup and method

  • HardwareIntel Core Ultra 7 165H, NVIDIA RTX 3000 Ada, 64 GB RAM, Windows 11 Pro.
  • VersionsLoupe upcoming release (the current 0.1.6-beta.3 is shown where it differs). Creo Parametric 12.4.4.0. SOLIDWORKS 2023 SP02.1, 3D Interconnect on (the default). Default settings everywhere.
  • Cold startEach program is closed and Windows' standby file cache is cleared before every open, and the run waits until the PC is idle.
  • TimingScreen recorded at 60 fps. The test script opens the file in the program, as a double-click would, and draws a marker on screen at that instant to set time zero; the stop frame is picked by eye, so times are good to about ±1/60 s.
  • ClicksCounted by a low-level mouse hook between the start key and the last file written.
